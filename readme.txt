Introducción del proyecto: Generar y utilizar las diferentes herramientas Plotly y Dash para la generación
de Dashboard en una aplicación de mortalidad.

Objetivo: Resolver y generar una aplicación para analizar la mortalidad de colombianos en el ano 2029.

Estructura del proyecto: 

Para generar esta aplicación primero se genero una pequeña aplicación donde se integran los diferentes
Excel  donde esta la información a analizar, para generar una  aplicación muy practica se integra primero
en un solo Excel los datos o columnas principales necesarias para lograr generar el dashboard y generar
los diferentes formatos de visualización para generar el análisis de datos necesarios.



Requisitos: Librerías y versiones necesarias para ejecutar la aplicación.

1. aplicación llamada estadística.py
   Excel denominado mortalidad_2019.xlsx
   IP para generar acceso a la dashboard, genera la siguiente linea de código cuando incia a
   cargar.

   Dash is running on http://127.0.0.1:8050/

 * Serving Flask app 'estadistica'
 * Debug mode: on



Despliegue (por ejemplo, en Render): Pasos seguidos para desplegar la aplicación.

   1. correr el programa e Python, aquí da un aviso on  donde ya esta generada y corriendo la app.
   2. acceder a la ip respectiva, http://127.0.0.1:8050/


Software: Herramientas utilizadas (Python, Dash, Plotly).
